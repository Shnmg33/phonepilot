# PhonePilot 手机原生桥接（iQOO Z3 方案）

此方案由手机直接通过 HTTPS 连接云服务器，不需要常开电脑，不需要 Root，也不依赖日常 ADB。AI 推理、任务调度、网页、日志与技能库均留在云端。手机只读取界面、按需截图、执行结构化动作并回传结果。

**交付状态：0.2.0 debug APK 已成功编译，通过 Android lint、APK 签名与 zipalign 校验；尚未在 iQOO Z3 真机验收。** 完整交付包附带 `releases/phonepilot-0.2.0-debug.apk`。源码包也可按下述方法在云服务器或 GitHub Actions 重新构建。

## 直接安装已构建的 APK

将 `phonepilot-0.2.0-debug.apk` 下载到手机，用系统安装器打开；若系统询问安装来源权限，仅为你正在使用的下载/文件管理应用按需授权。此包使用 Android Debug 签名，适合当前个人验收，不是应用商店正式发布版本。最低 Android 11，目标 Android 15，包名 `com.phonepilot.bridge`。未内置模型密钥、服务器地址或桥接令牌。

安装后按本文“安装与首次连接”配置。APK SHA-256 与签名证书摘要见完整包 `releases/BUILD-INFO.json`。

## 手机要求与实际边界

- Android 11 / API 30 及以上。请在 iQOO Z3 的“设置 → 关于手机”确认当前版本；仅凭型号不能确认已安装的系统版本。
- 由你在系统设置中主动启用 PhonePilot 无障碍服务，并在应用内启动桥接。
- 普通应用无需 Root；也不能解锁密码锁。手机息屏/锁屏时，服务器保留新任务为排队状态，亮屏解锁并恢复心跳后继续领取。
- 已开始的任务遇到锁屏或系统拒绝操作会停止并记录错误，不会伪造完成结果。
- iQOO 的 OriginOS / Funtouch OS 后台限制因版本而异。无障碍服务、通知、取消电池限制均不能保证绝对不被系统终止，必须实测。
- 最低权限方案只在执行单个命令时持有最多 30 秒的 CPU 唤醒锁，不持有全天唤醒锁，也不会自动点亮或解锁屏幕。自动定时操作是否可行，取决于手机当时可操作状态。

## 构建方法 A：在自己的云服务器生成 APK

以 Ubuntu / Debian 为例，安装构建依赖；至少预留数 GB 磁盘空间，首次构建需要下载 SDK 和 Gradle。

```bash
sudo apt-get update
sudo apt-get install -y openjdk-17-jdk curl unzip
cd phonepilot
bash android/build-on-server.sh
```

脚本下载 Android command-line tools、Android 35 SDK 和 Gradle 8.11.1，并调用 Android Gradle Plugin 8.9.2。SDK 许可由你在终端阅读并接受。默认工具缓存位于 `android/.build-tools/`；可通过 `PHONEPILOT_BUILD_TOOLS` 指定其他目录。该目录和构建产物不应提交到源码仓库或复制到手机。

脚本成功完成后，安装包位于：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

这是一份供个人验收使用的 **debug APK**，不能当作已发布的正式版本。通过你自己的私有文件传输方式将 APK 下载到手机，再安装。不要把服务器 `.env` 一起传给手机。

后续版本需要沿用相同签名才能覆盖升级。在同一构建账号/目录中保留 Android debug keystore；不要对外分享签名密钥。更换机器构建或使用不同 CI 运行器可能产生不同签名，卸载后重装会丢失本机配置和设备标识。

## 构建方法 B：GitHub Actions 云端构建

仓库已包含 `.github/workflows/android.yml`。把完整项目作为仓库根目录上传到你自己的仓库后，进入 **Actions → Build Android bridge → Run workflow**。

工作流调用 `assembleDebug` 与 `lintDebug`，成功后下载 `phonepilot-android-debug` artifact，解压取得 APK 和 lint 报告。尚未在你的 GitHub 仓库执行这份工作流。

需要 Android SDK、Google Maven、Maven Central 和 Gradle 下载地址可访问。构建不需要你的管理员令牌、桥接令牌或任何模型 API Key。

## 安装与首次连接

1. 按根目录 README 部署服务器，配置有效 HTTPS。手机端只接受 HTTPS 域名根地址，例如 `https://phone.example.com`，不接受明文 HTTP 或自签证书绕过。
2. 安装 APK，打开 **PhonePilot 手机桥接**。
3. 填写服务器地址、固定桥接 ID（例如 `iqoo`）及服务器 `.env` 中的 `BRIDGE_TOKEN`。
4. 点击“打开无障碍设置”，找到 PhonePilot，阅读系统提示并启用。
5. 返回应用，阅读并勾选使用说明，点击“保存配置并启动桥接”。Android 13+ 可按提示允许通知，便于通过通知停止。
6. 返回桌面或目标应用，保持亮屏且已解锁。配置页禁止截屏，桥接也拒绝读取或控制自己的配置页。
7. 打开服务器网页的“设备连接”，确认出现“手机原生 · HTTPS”，设备在线且未锁屏。

如果系统对侧载应用的无障碍权限显示“受限制的设置”，仅在确认 APK 为你自己构建的可信版本后，按系统提供的应用信息页授权流程处理。菜单是否存在、名称和位置以实际系统为准。

## iQOO 后台运行设置

在系统设置中查找本应用对应的以下选项；不同版本可能叫法不同：

- 应用权限 / 自启动：允许应用自启动（若系统提供）。
- 电池 / 后台耗电管理：允许后台运行或取消电池优化限制。
- 通知：允许连接状态通知，通知中有“停止桥接”。
- 最近任务界面：按系统支持方式锁定应用卡片，避免“一键清理”时被清除。

APK 中提供系统电池优化列表入口，不会自动修改这些设置。系统重绑定无障碍服务时，会依据之前的启动状态尝试重连；强制停止、重启、解锁前及厂商回收策略都需要单独验收。

## 功能与输入语义

| 功能 | 原生实现与限制 |
| --- | --- |
| 读取界面 | 无障碍节点树，最多 250 个可用节点，密码节点文字遮蔽 |
| 截图 | Android 无障碍截图 API，仅视觉模型观察或手动预览时请求；安全窗口可能拒绝 |
| 点击 / 滑动 | 系统无障碍手势，校验屏幕范围，等待执行/取消回调 |
| 输入文字 | 支持中文，使用 `ACTION_SET_TEXT` **替换整个聚焦输入框**，不需要 ADBKeyboard |
| 按键 | 返回、主屏、最近任务；回车/Tab/删除取决于输入控件支持，不等价于任意底层按键注入 |
| 启动应用 | 已安装且可通过 launcher 入口解析的包名，启动后仍需模型观察验证 |
| 后台连接 | 空闲长轮询约 15 秒一次；失败重连；不运行本地模型 |
| 停止 | 应用内或通知中停止。已发送的单次手势可能仍完成 |

同一设备的 ADB 文字输入通常追加文本，原生输入替换文本；手机会把能力说明提供给服务器，模型提示也区分这两种语义。WebView、Canvas、游戏和某些定制输入框可能不支持节点读取或文字设置，必须实测具体应用。

## 断线与数据处理

服务器只领取一次命令，手机仅重试“结果回传”，不会因网络失败重新执行动作。进程被终止或结果未送达时，服务器可能显示“桥接命令待确认”；先检查手机状态，再在网页清除该状态。未确认结束的命令会阻止该设备的新任务开始。

桥接令牌通过 Android Keystore 加密存储；APK 禁用应用备份，配置页禁止截屏。界面内容只在收到观察命令时读取，截图只在要求时采集；页面中非密码字段及截图仍可能包含私人信息，并会进入你选择的服务器/模型处理流程。

当前属于单用户自托管版本：服务器为所有信任的桥接端使用共同 BRIDGE_TOKEN，尚未实现每台手机独立密钥、多租户与证书固定。清空手机应用数据/卸载会改变设备标识；原定时计划需重新选择新设备后创建。

## 真机验收顺序

1. 先确认 APK 能安装、打开和启用无障碍；观察手机端连接状态。
2. 在服务器手动查看截图，执行返回/主屏，再点击、滑动。
3. 打开普通输入框，输入中文，验证整框替换；测试回车支持情况。
4. 用 DeepSeek 运行“打开设置并查看 Android 版本”，确认节点观察、动作、结果与技能提炼。
5. 锁屏后创建任务，确认保持排队；解锁回桌面，确认继续执行。
6. 分别测试断网重连、停止桥接、系统清理应用和重启手机，确保没有重复执行旧操作。
7. 做长时间后台与电量观察，再决定是否用于无人值守定时任务。当前没有实测续航或 CPU/内存消耗数据。
